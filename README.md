# 🥽 VR Rhythm Card Battle

A VR rhythm-based game developed in Unity by two developers, where players must play cards in sync with the music while facing an opponent in a reactive battle system.

## 🎮 About the Game

*VR Rhythm Card Battle* is a virtual reality rhythm game where timing and precision are key.

The player must draw and play cards in rhythm to attack, defend, and react to an opponent also following the beat. The gameplay combines rhythm mechanics with competitive VR interaction.

All visuals and assets were created by us.

## 🧠 Core Idea

This project explores the combination of:
- rhythm-based gameplay
- card-based combat systems
- immersive VR interaction
- real-time competitive timing

## 🛠️ Features

- VR interaction system (hand-based card selection and play)
- Rhythm-based gameplay mechanics
- Enemy AI reacting to player rhythm
- Card system (attack, defense, timing effects)
- Custom-made graphics and visual assets
- Immersive VR feedback and effects

## ⚙️ Built With

- Unity
- XR Interaction Toolkit 
- C#
- Custom-made art assets

## 👥 Development

- Developed in a team of 2
- Focused on VR interaction and rhythm synchronization
- Responsibilities split between programming and visual production
- Built as a prototype exploring VR rhythm combat mechanics

## 🎯 Goal of the Project

The goal was to experiment with:
- rhythm-based interaction in VR
- tactile card gameplay mechanics
- immersive competitive game design
- syncing gameplay to audio and timing systems
